# MNIST Digit Classification 🧠

A comparison of **Machine Learning and Deep Learning models** for handwritten digit classification using the MNIST dataset.

## Models

### Machine Learning

* Logistic Regression (LR)
* K-Nearest Neighbors (KNN)
* Gaussian Naive Bayes (GaussianNB)
* GridSearchCV for hyperparameter tuning

### Deep Learning

* Artificial Neural Network (ANN)
* Convolutional Neural Network (CNN)

## Tech Stack

* Python
* NumPy & Pandas
* Scikit-learn
* PyTorch
* Matplotlib & Seaborn
* Jupyter Notebook

## Dataset

**MNIST** — 28×28 grayscale handwritten digit images representing digits `0–9`.

## Concepts Covered

* Data preprocessing & visualization
* Normalization
* Train/Test Split
* Hyperparameter tuning
* ANN & CNN
* PyTorch Dataset & DataLoader
* Model training & evaluation
* Accuracy comparison
* Underfitting & Overfitting

**Goal:** Compare traditional ML models with neural networks on the same image classification problem.
